⚠️  IMPORTANT: MONGODB CONNECTION REQUIRED

The Backend API is waiting for MongoDB. Choose ONE option:

OPTION 1: MongoDB Atlas (Cloud) - EASIEST ✨
───────────────────────────────────────────
1. Open: https://www.mongodb.com/cloud/atlas
2. Create FREE account (or login)
3. Create a FREE cluster
4. Click "Connect" → "Drivers" → Node.js → Copy connection string
5. Edit: medilink-backend\.env
   Find: MONGODB_URI=mongodb://localhost:27017/medilink
   Replace with: MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/medilink
6. Backend will auto-reconnect! ✓

Example MongoDB Atlas URI:
  mongodb+srv://user123:myPassword@medilink-cluster.mongodb.net/medilink?retryWrites=true

OPTION 2: MongoDB Local
───────────────────────
1. Download: https://www.mongodb.com/try/download/community
2. Run installer
3. Start MongoDB service (should be default)
4. Backend will connect automatically ✓

🔧 IF SOMETHING DOESN'T WORK:

Backend stuck waiting for MongoDB?
→ Update .env with MongoDB URI (see section above)
→ Backend will attempt reconnect every 10 seconds

Dashboard shows blank?
→ Open browser console: F12 → Console tab
→ Check for errors
→ Refresh page: Ctrl+R

AI Service won't start?
→ Verify Python installation: python --version
→ Check venv: cd medilink-ai && .\venv\Scripts\python.exe --version
→ Reinstall deps: pip install -r requirements.txt

Mobile app won't connect?
→ Update API_BASE_URL in medilink-mobile/lib/providers/auth_provider.dart
→ Default: http://localhost:5000
→ For Android emulator: http://10.0.2.2:5000
